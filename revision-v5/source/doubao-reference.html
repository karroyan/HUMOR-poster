1  What Makes a Caption a Meme?

Meme generation is not image captioning. A meme = a fixed template encoding a relational schema + context-specific text filled into designated positions. The same visual template affords dramatically different punchlines depending on the inferred scenario.

Case: The "Distracted Boyfriend" template

Humans first parse the template's relational core: A (attention-shifting subject) is drawn to B (newly focused entity), neglecting C (the old object of attachment). This abstract schema maps onto any context expressing "infatuation with the new and abandonment of the old."

Technology theme + keyword "Apple fanatic"
Align the infatuation-with-new schema to product updates: the man ↔ Apple fans, the other woman ↔ iPhone 11, the girlfriend ↔ iPhone 10.

Same template, other contexts
• Workplace: a leader attracted to a new hire — "new vs. old" office politics.
• Daily life: resisting a tempting purchase / an unhealthy habit.
Direct generation jumps from pixels to a single caption — no layered abstraction, no genuine discovery. HUMOR-CoT first parses the template's metaphorical schema, then grounds it in the user's context.

Why we compare within a template

A global "funniness score" assumes unrelated jokes share one scale. We instead learn relative quality inside a coherent group G (usually one template), where human judgments are reliable.

Key observation: Absolute VLM scores barely separate real memes from blank images; group-wise ranks provide clearer distinctions. Independent check: 9 annotators, 5 groups, 30 memes. Gemini–human agreement: Spearman 0.72; Kendall τ = 0.63.
Why this task matters: Direct caption supervision collapses diverse reasoning paths into one shallow output. We need to explore multiple plausible contexts, anchor to a high-quality path, and optimize toward human preference — an open-ended, group-wise reasoning problem.

2  HUMOR: Hierarchical Understanding & Meme Optimization

HUMOR = multi-path hierarchical CoT + group-wise pairwise reward + KL-controlled GRPO.

2.1  Hierarchical Chain-of-Thought

Stage 1 Template-level intent: parse visual elements, then explore multiple plausible contexts (emotions, intents, scenarios) — like brainstorming several possible jokes.

Stage 2 Context-specific grounding: anchor one path to the real meme's actual user context. At inference, rank Stage-1 paths by the reward model.

Stage 1 expands reasoning breadth; Stage 2 anchors a canonical path from real captions.
Er~Pθ[h̃G(r)]  ≥  1 − (1 − α)δ

Promising paths retain probability mass α; others are at most moderately worse (δ). Exploration + anchoring preserves a conditional humor lower bound.

2.2  Pairwise Reward Modeling

Humor has no global scale — we adopt an order-consistent within-group reward: trained only on relative judgments (mi > mj) among memes sharing the same template.

Five difficulty tiers: Wrong text → Wrong location → Boring → Detailed boring → Generated. EBC aggregates sparse pairs into a stable group ranking.

2.3  Group-wise Policy Optimization (GRPO)

Fine-tune toward higher-ranked captions within each template group, with a corrected KL term bounding deviation.

LGRPO = E(I,G)[− Σ qG(mk) log πθ(ck|I) + β EI[KL(πθ ‖ πref)]]
Pipeline: multi-path CoT SFT → pairwise reward model (EBC) → group-wise GRPO.
Theoretical guarantee: if KL ≤ τ, expected humor cannot drop by more than √(τ/2). Rank-consistent reward + KL control = bounded, stable improvement.
