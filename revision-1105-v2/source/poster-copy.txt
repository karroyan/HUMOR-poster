1  EXPLORE · REFERENCE CAPTION HIDDEN
Infer the template’s intent; explore plausible situations
before seeing the answer.
Confusing work problem → bewilderment
Bad joke → an exaggerated painful response
Social ignorance → refusing to listen
2  REVERSE-ANCHOR · REFERENCE REVEALED
Infer the actual context from the caption; explain
why an existing path fits it.
Keep the other explored associations.
Reveal the answer only after exploration to reduce
answer-driven rationalization.
Generation: template + user intent; no reference caption.
Humor is subjective; an absolute score is hard to calibrate.
With the template and intended theme fixed, relative
preference is easier to interpret.
