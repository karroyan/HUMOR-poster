# 本版介绍思路与措辞依据

## 一条连续的问题链

**模板支持多种意思 → 怎样不被答案束缚地探索 → 怎样判断哪个表达更好 → 怎样把比较转成可训练信号 → 怎样兼顾表达变化和质量。**

## 约三分钟中文讲解

我们研究如何给一个 meme 模板生成符合用户情境的幽默配文。左上角的例子中，图像表达的是注意力从旧对象转向新对象；给定“苹果粉丝”的主题，模型要把这个关系对应到苹果粉丝、新手机和旧手机。问题在于：一个模板可以支持很多解释，我们既需要探索不同的想法，也需要判断哪些表达更好。

A 处理探索。我们在制作推理监督时把过程分成两步：第一步完全不给真实配文，让模型根据模板理解意图，并尽可能展开不同的情景。这里 Mr. Bean 的表情可以对应工作中的困惑、听到烂笑话的痛苦，或者社交中拒绝倾听。等这些路径已经出现后，第二步才给真实配文，从它反推实际情境，说明为什么已有的一条路径与这个情境兼容。这样，答案用于后续落地，而不是从一开始就限定探索方向。它旨在减少答案驱动的事后解释；不能声称完全消除泄漏。训练完成后，实际生成只需要模板和用户意图。

B 处理比较。幽默本身很主观，跨模板统一给绝对分很难校准。但当模板和目标情境固定时，比较两个候选哪个表达更好，通常有更清楚的共同参照。为获得这样的训练信号，我们构造了五种难度：文本不相关、位置错误、平淡表达、细微措辞劣化和模型生成候选。奖励模型先学习成对偏好概率；再将每个候选对其他候选的预计胜场相加，也就是 EBC，得到组内分数和排序，并形成局部策略目标。

C 把这条链串起来。探索能带来更多表达方向，也可能包含较弱的笑话；因此我们用偏好引导生成概率，同时约束更新不要偏离 CoT 参考策略过远。上面的公式描述条件成立时推理路径质量的缺口，下面的公式限制策略更新相对参考模型可能下降的幅度。两者说明控制质量损失的思路，多样性收益则由实验来检验。

先看主表旁的散点图。横轴是改变用户情境后输出变化的距离，纵轴是人类幽默评分。Subquestion 变化很大，但幽默评分较低，说明变化多本身并不够。HUMOR-CoT 相对同一 7B 基线在两项指标上都更好。RL 的幽默评分进一步提高，但部分其他指标有取舍，所以我们标为初步结果。

右侧是真实生成样例。底部05检验奖励模型的排序是否与人类偏好一致。100名参与者提供5个模板的MaxDiff排序，训练后的Keye在各组达到约0.77–0.78的Kendall相关性；其他backbone的改善没有这么一致。06的意图还原实验则进一步检查生成结果是否表达了用户指定的情绪、意图、主题和风格：让 VLM 从生成内容重新识别属性，再与输入比较。HUMOR 7B 四项都超过同规模基线，三项超过 32B。最后，20个未见模板的曲线提供跨模板表现的补充证据。

## DPO：可以怎么说，不能怎么说

不建议说“好坏模糊，所以 DPO 不适合 meme”。DPO 本来就从相对偏好学习，不要求一个普适、客观的好坏标准。常见 DPO 目标可以理解为提高优选样本相对非优选样本、相对于参考策略的对数概率优势；这不是简单拉大文本或语义距离。标签噪声和模糊性也同样影响 reward model 和 EBC，并非 DPO 独有问题。

本论文没有 DPO 对照结果，因此不能声称其效果不好。我们的选择可正面解释为：希望显式比较同组多个候选，将预期胜场聚合为可读的局部排序，再形成策略目标。EBC 提供的是这一步聚合。

## 对“保证幽默度的同时提升多样性”的精确表述

建议现场说：“我们通过多路径探索扩大表达空间，再通过组内偏好和受约束更新控制质量；实验显示，相比基线，我们同时改善了幽默度和情境变化指标。”

不建议说：“CoT一定降低幽默度，随后算法证明幽默完全不受损。”现有主表恰好显示 HUMOR-CoT 相对7B基线的幽默评分提高；理论只在特定假设下给出质量下界和可能退化的上限。路径期望与最终caption的H也是不同对象，不应未经连接假设直接拼成一个全流程最优保证。
